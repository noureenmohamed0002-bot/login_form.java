☕ Java Login Form

A simple desktop login application built with Java AWT.

✨ Features

- 🔐 Username and password validation
- 👥 Three user roles: Student, TA, and Professor
- ⚠️ Error messages for incorrect information
- 🔒 Login locks after 3 incorrect password attempts
- 👋 Welcome page showing the username and role
- ❌ Cancel button to close the application

🛠️ Technologies

- Java
- Java AWT
- Java Swing ("JOptionPane")

▶️ How to Run

1. Install the Java JDK.

2. Open the project folder in VS Code.

3. Open the terminal and compile the code:
   
   javac LoginFormTask.java

4. Run the application:
   
   java LoginFormTask

🎯 Project Goal

This project practices Java basics, GUI development, event handling, and simple login authentication.
